# Trabajo Práctico Integrador 1 - API REST

Sistema de gestión de blog personal desarrollado con Node.js, Express, Sequelize ORM y MySQL. Incluye autenticación mediante JWT (cookies `httpOnly`), hasheo de contraseñas, validaciones, relaciones entre modelos (1:1, 1:N, N:M) y borrado lógico (_soft delete_).

## Tecnologías utilizadas

- **Runtime:** Node.js (ESModules)
- **Framework:** Express.js
- **ORM:** Sequelize
- **Base de Datos:** MySQL
- **Autenticación:** JSON Web Tokens (JWT) y bcrypt
- **Control de Versiones:** Git / GitHub
